# COFFEE SHOP MANAGEMENT WEB
A backend-driven coffee shop management system developed with Spring Boot and MySQL, supporting product management, order processing, table management, revenue statistics, JWT-based authentication, and role-based authorization for Admin and Staff users.

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- RESTful APIs

### Database
- MySQL

### Architecture
- MVC Architecture

### DevOps & Tools
- Docker
- Docker Compose
- Git & GitHub
- Postman
